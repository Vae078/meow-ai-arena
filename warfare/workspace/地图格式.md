# 地图 / 关卡 JSON 格式

> `workspace/maps/`（对抗图）和 `workspace/levels/`（闯关图）的 `.json` 格式。加载与校验逻辑在 `engine/src/scenario.cpp`。改图时可用 `python play.py map <名字>` 或网页编辑器 `python editor/map_editor.py` 验证。

## 1. 顶层字段

```json
{
 "name": "山河关",        // 地图名（战报/回放显示）
 "mode": "duel",          // duel(1v1) | melee(四人混战) | level(闯关) | sandbox(测试)
 "theme": "山地峡谷",     // 渲染主题（可选）
 "desc": "……",           // 描述（可选）
 "bounds": [-240,-210,240,210],  // 地图范围 [x0,z0,x1,z1]
 "time_limit": 480,      // 时限（秒）
 "kill_y": -5,           // 掉到这个高度以下出局
 "on_timeout": "lose",   // 时间到判负（"lose"|"win"）
 "water": {"level": -0.6},   // 水面：固定 level，或潮水 {"tide":{"t0":20,"t1":75,"h0":0,"h1":4}}
 "terrain": [ … ],       // 地形图元（见 §2）
 "zones": [ … ],         // 区域/据点（见 §3）
 "score_zone": "",       // 计分区名字（非 AAS 计分模式用）
 "seats": [ … ],         // 座位/出生点（见 §4）
 "props": [ … ],         // 道具（见 §5，关卡常用）
 "units": [ … ],         // 敌军/中立单位（见 §6，关卡用）
 "objectives": { … },    // 胜负条件（见 §7，关卡用）
 "boss": { … }           // 镇山兽参数（见 §8，第 5 关）
}
```

**坐标约定**：地形/据点/道具/敌军/水面用**世界坐标**；`seats[].deploy`（布阵区）和布阵文件用**我方视角**（相对 `origin`，随 `yaw` 旋转）。所有 `yaw` 字段都是**角度制**（引擎读入时转弧度）。

**mode 约束**：`duel` 要正好 2 个 seats，`melee` 要 4 个，`level` 要 1 个。

## 2. terrain（地形图元）

都是静止实心块；没被盖住的地方是空的，掉下去（低于 `kill_y`）出局。

| 类型 | 字段 | 说明 |
|---|---|---|
| `box` | `min`/`max`（或 `c`/`h`）、`yaw` | 盒子。`min/max` 是两对角；`c/h` 是中心+半尺寸；`yaw` 绕 y 轴转（度） |
| `ramp` | `from` `to` `width` `h0` `h1` `base` | 坡道：从 (from) 到 (to) 的中线，宽 `width`，两端顶面高 `h0`/`h1`，底面高 `base` |
| `cyl` | `c` `r` `y0` `y1` `segs` | 圆柱：中心 `c:[x,z]`，半径 `r`，从 `y0` 到 `y1` |
| `mound` | `c` `r0` `r1` `y0` `y1` `segs` | 圆台：底半径 `r0`（在 `y0`）、顶半径 `r1`（在 `y1`），可做山丘/高地 |
| `hull` | `pts` | 任意凸包：`pts` 是 `[x,y,z]` 数组（≥4 点） |
| `forest` | `min` `max` `spacing` `r` `h` `y0` | 树林：矩形 `min:[x,z]` `max:[x,z]` 内按 `spacing` 间距种树干圆柱（确定性抖动） |

每个图元还有：`mat`（材质，只给渲染用）、`tag`（同名图元可一起被移除，如"桥中段"）、`boss_stun`（镇山兽撞上会晕，用于石墙）。

**关键**：山壁/墙要高于兵种最大翻越高度 1.6 米才能挡住（否则会被爬过去）。

## 3. zones（区域 / 据点）

```json
{"name":"湖心岛", "circle":[0,0,13], "order":3}
{"name":"泥塘", "rect":[-15,-4.5,15,4], "speed_mul":0.4, "stick_secs":4}
```

| 字段 | 说明 |
|---|---|
| `name` | 名字（objectives 的 zone 引用它） |
| `circle:[cx,cz,r]` 或 `rect:[x0,z0,x1,z1]` | 形状（二选一） |
| `speed_mul` | 减速区（泥塘）：区里单位最高速度乘这个数（<1） |
| `stick_secs` | 出区后继续带泥的秒数（0 = 出来就恢复） |
| `score` | 计分据点：>0 表示每回合归属方得这么多分 |
| `order` | **AAS 顺序占点**：链上序号（0..N-1）；-1 = 不是顺序占点 |

AAS 图：据点全部 `order>=0`（初始中立），从 `order 0` 端（team0）和 `order N-1` 端（team1）相向推进。

## 4. seats（座位 / 出生点）

```json
{"origin":[0,-195], "yaw":0, "deploy":[[-24,0,24,14]], "budget":1000, "max_units":80}
```

| 字段 | 说明 |
|---|---|
| `origin` | 座位原点（世界坐标），我方视角的原点 |
| `yaw` | 朝向（度）：0 = 朝 +z（北），180 = 朝 -z（南） |
| `deploy` | 布阵区，我方视角矩形数组 `[[x0,z0,x1,z1],…]` |
| `budget` | 布阵预算（造价上限） |
| `max_units` | 布阵人数上限 |
| `limits` | 每兵种限购 `{"兵种中文名":个数}`（可省，不写=不限） |
| `lord` | 主帅起点 `{"x":…,"z":…,"yaw":…}`（世界坐标，可省） |

## 5. props（道具）

```json
{"type":"snowball", "x":0, "y":0, "z":0, "r":1.5, "team":-1, "tag":"", "hp":300}
```

| 字段 | 说明 |
|---|---|
| `type` | `snowball`(雪球) / `keg`(火药桶) / `flag`(军旗) / `barrier`(木栅) / `gate`(木栅门) / `pillar`(立石) |
| `x y z` | 位置（世界坐标；`y` < 0 自动放地面） |
| `team` | 军旗属于哪一方，其他道具 -1（中立） |
| `tag` | 标签（火药桶 `breaks` 和 objectives `destroy` 用它） |
| 其余 | `r`(半径) `hp` `mass` `push_secs` `yaw` `release_speed` `dmg_k` `dmg_max` `size:[x,y,z]` `boss_hits`(撞几次碎) `breaks`(炸掉的地形 tag) `break_delay` |

## 6. units（敌军 / 中立单位，关卡用）

单个单位，或 `group` 方阵：

```json
{"type":"骑兵", "x":-9, "z":17, "yaw":180, "behavior":"default", "team":1, "tag":"先锋"}
{"group":{"type":"新兵","x":0,"z":24,"yaw":180,"behavior":"default","rows":2,"cols":12,"dx":1.5,"dz":1.4}}
```

| 字段 | 说明 |
|---|---|
| `type` | 兵种（中文名或英文 id，如 `"骑兵"` / `"cavalry"`） |
| `x z y` | 位置（世界坐标；`y` < 0 自动放地面） |
| `yaw` | 朝向（度） |
| `behavior` | `default`(自由) / `hold`(原地守) / `march`(行军) / `idle`(不动) |
| `team` | 队伍（默认 1） |
| 行军 | `to:[x,z]` 或 `to_tag` 目标；`route:[[x,z],…]` 路点；`alt_route` 备用路线 + `alt_trigger`(触发 tag) + `alt_region`(矩形) + `rally_idx/rally_secs/rally_r`(集结) |
| 其他 | `tag` `delay`(开场延迟秒) `hp`(改血量) `squad`(小队名) `sortie`(守军出击) |
| `group` | 方阵：`rows` 排 × `cols` 列，`dx`/`dz` 间距，从 `(x,z)` 向后排 |

## 7. objectives（胜负条件，关卡用）

```json
"objectives": {
  "win":  [{"type":"eliminate","team":1}],
  "lose": [{"type":"dead","tag":"主帅"}],
  "on_timeout": "lose"
}
```

`type`：`eliminate`(全歼某队) / `destroy`(摧毁带 tag 的道具/单位) / `dead`(带 tag 的单位死了) / `zone_held`(守住 zone 持续 secs 秒) / `reach`(够 count 人到达 zone)。`win` 任意一条达成即胜，`lose` 任意一条即败。

## 8. boss（镇山兽参数，第 5 关）

```json
"boss": {"interval":6, "paw_secs":1.2, "charge_speed":13, "overshoot":8,
         "charge_dmg":60, "charge_impulse":900, "stun_secs":4, "stun_mul":1.5,
         "front_mul":0.5, "paw_turn":3.0}
```

全部有默认值，可省略。

## 9. 验证

改完图后：`python play.py map <名字>` 跑 0.1 秒确认能加载（地形采样、据点、座位都正常）；实际打一场看推进是否合理。规则数值可用 `--cfg 名字=值` 临时调（`war info` 看全部字段名）。
